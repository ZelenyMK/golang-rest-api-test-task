# Тестовое задание по разработке REST API на Go
## Как запустить?
В директории проекта:
```
go run cmd/test-task/main.go
```
## Как запустить тесты?
В директории проекта:
```
go test ./test/
```

##Зависимости:
go-sqlite3, chi
